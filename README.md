# 店舗POS(オフライン対応PWA版)

タブレット1台で完結する、オフライン動作対応のPOSアプリです。
ホーム画面に追加すると、通常のアプリのように起動できます。

## 中身

```
index.html          … アプリの入り口
app.jsx             … アプリ本体(ブラウザ上でJSXを直接読み込み)
manifest.json        … PWA設定(アプリ名・アイコン・起動方法)
service-worker.js    … オフラインキャッシュの仕組み
icons/               … ホーム画面用アイコン各種
```

## データの保存場所

このアプリのデータ(商品・座席・売上履歴・設定)は、**タブレットのブラウザ内(localStorage)** に保存されます。
サーバーには一切送信されません。そのため:

- 他のタブレットやPCとデータは共有されません(1台で完結)
- ブラウザの「サイトデータを消去」やアプリの再インストールを行うと、保存したデータは消えます
- **マスタ設定 → データ管理** から定期的にJSONバックアップを書き出しておくことを強くおすすめします

## 公開手順(GitHub Pages)

1. GitHubで新しいリポジトリを作成する(例: `pos-app`)
2. このフォルダの中身一式(`index.html`, `app.jsx`, `manifest.json`, `service-worker.js`, `icons/`)をそのままリポジトリのルートにアップロードする
3. リポジトリの **Settings → Pages** を開く
4. "Source" を `Deploy from a branch` にし、ブランチを `main`、フォルダを `/ (root)` に設定して保存する
5. 数分待つと `https://ユーザー名.github.io/pos-app/` のようなURLが発行される

## タブレットへの導入手順

1. タブレットのブラウザ(Safari / Chromeなど)で、上記で発行されたURLを開く
   - **この初回アクセス時だけはインターネット接続が必要です**(React本体などをキャッシュに保存するため)
2. 数秒待ち、画面が正常に表示されることを確認する
3. ブラウザの共有メニュー(Safariなら「共有」ボタン、Chromeなら「⋮」メニュー)から
   **「ホーム画面に追加」** を選択する
4. ホーム画面に追加されたアイコンから起動すると、通常のアプリのように全画面で開く
5. 一度上記の手順を済ませれば、以降は機内モードやWi-Fiオフの状態でも起動・動作します

## アップデートしたいとき

`app.jsx` などのファイルを更新してGitHub Pagesに再アップロードすると、
タブレットが次にオンラインになったタイミングで自動的に新しい内容に切り替わります
(裏側でキャッシュが更新される仕組みのため、既存のデータが消えることはありません)。

強制的にすぐ反映させたい場合は、`service-worker.js` 内の `CACHE_VERSION` の数字を
書き換えてから再アップロードしてください。

## バックアップの取り扱い

**マスタ設定 → データ管理** から:

- **全データをJSONで書き出す**: 商品・座席・売上履歴・税/サービス料設定をすべて含む完全バックアップ
- **売上履歴のみCSVで書き出す**: 表計算ソフトで開ける売上一覧

書き出したファイルは、タブレットのダウンロードフォルダに保存されます。
定期的にPCやクラウドストレージ(Googleドライブなど)にコピーしておくと安心です。

復元する際は、同じ画面でJSONファイルを選択してください。
**復元すると現在タブレットにあるデータは上書きされます**(元に戻せません)。
